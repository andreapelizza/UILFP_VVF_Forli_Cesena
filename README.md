# UIL FP Vigili del Fuoco Forlì-Cesena

Strumenti della Segreteria Provinciale UIL FP VV.F. Forlì-Cesena, pubblicati con GitHub Pages.

## Invio nota via PEC (`index.html`)
Prepara una PEC per una nota sindacale: dati della nota (data, protocollo, oggetto), destinatari standard, oggetto e testo della PEC, nome del file PDF.
Ogni campo ha il pulsante **Copia** da incollare nella PEC Aruba; il pulsante **Apri bozza** usa un link `mailto:`.
L'allegato (PDF firmato digitalmente) si aggiunge a mano.

Nessun dato viene inviato a server esterni: le preferenze (ultimo protocollo, destinatari aggiunti) restano solo nel browser.
